Batooty romantic website — GitHub Pages

Upload ALL files in this folder directly to the ROOT of your GitHub repository (do not put them inside another folder).

1. Create/open your GitHub repository.
2. Upload index.html, .nojekyll, README.txt, and every image/video/music file.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for deployment and open the Pages URL.

Keep all media files alongside index.html in the repository root; the page references them by filename.
